# Open data pages, updated every day

Small tables built each day from official open data with the EuroScrape Actors. Free to read, link and reuse, with the source named on each page.

- [Cheapest electricity hours in Europe](electricity-cheapest-hours.md): tomorrow's day-ahead prices in 28 bidding zones, with the three cheapest hours of the day.
- [Carburant le moins cher dans 20 villes de France](prix-carburants-villes.md): the lowest diesel, E10 and SP98 price around twenty French cities, today (in French).

Each table has a JSON copy next to it. For any other zone, city or date, run the Actor behind the page.
